# PythonProject

Проект для практики автоматизации тестирования.

---

## Структура
- `Practice/` — старые задания, самые первые тесты, азы  
- `Practice2/` — UI тесты (pytest + Playwright/Selenium)

---

## Запуск UI тестов
```bash
cd Practice2
pytest
```

## Переменные окружения (креды)

Для UI тестов нужен файл `.env` в папке `Practice2`.

Файл `.env` не должен попадать в репозиторий (содержит секреты).  
Добавьте `Practice2/.env` в `.gitignore`.

### Пример `Practice2/.env`
```env
GH_USER=ваш_логин
GH_PASS=ваш_пароль
```

## Негативная авторизация (GitHub)

В проекте реализован негативный UI-тест для GitHub авторизации
(неуспешный вход).

### Особенности реализации

- Для негативного сценария используется **случайно сгенерированный username**
  (буквы + цифры).
- Это сделано для выполнения условия курса: *"невалидный логин"*.
- GitHub не валидирует формат логина (email / username), но применяет
  anti-bot эвристики на уровне поведения.
- В связи с этим тест **может быть нестабильным** при изменениях логики
  на стороне GitHub.

### Примечание

В реальных проектах рекомендуется использовать:
- валидный username
- заведомо неверный пароль

Текущая реализация используется в учебных целях.
